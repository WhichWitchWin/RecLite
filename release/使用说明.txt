RecLite 轻录音
======================================================================

【快速开始】
双击 RecLite.exe 就能用。不用安装、不写注册表、不装额外组件。
录音默认存在同级的 Recordings 文件夹里，删掉整个文件夹就等于卸载干净
（系统临时目录里会留一个约 2.5MB 的解码库缓存，随时可以删）。

  注意：别放进 C:\Program Files 这类没有写入权限的目录，
        否则设置和录音都存不下来。放桌面、D 盘、U 盘都行。

【第一次运行如果弹窗】
如果出现「Windows 已保护你的电脑」，点【更多信息】→【仍要运行】。
程序没有购买数字签名证书，这是"未知发布者"提示，不是病毒警告。

  想以后不再弹：右键 exe → 属性 → 底部勾选「解除锁定」→ 确定。

【预录缓存 —— 本程序的核心】
它一直在后台记着"最近一段时间"，你按下录音时，这段会被接到录音开头，
所以不会错过刚才那句话。

  预录缓存   填几秒就留几秒。下拉框里能直接输入数字：
             60、90、2分30秒 都行。上限随采样率变（48kHz 时最长 600 秒）
  清空缓存   把已缓存的内容扔掉，重新开始
  存预录     把当前缓存单独存成一个 WAV 文件（位深跟随"保存格式"）
  保存时包含预录片段
             勾上后，录音会把预录那段一起写进文件

【录制】
  录制通道   麦克风 / 声卡输入，或任意播放设备的〔内录〕（录电脑发出的声音）
             最多支持 2 声道，超过 2 声道的设备会被拒绝使用
  录制音量   0~300%，只影响录进文件的内容，不影响你听到的声音
  暂停       暂停期间不写盘、不计时；点继续后接着录同一段

  录音进行中不能切换通道、不能改预录秒数 —— 避免一个文件里混两种格式。

【保存】
  保存格式   WAV：16 / 24 / 32 位浮点       MP3：128 / 192 / 256 / 320 kbps
             注：MP3 走 Windows 自带编码器，精简系统上如果没装对应组件，
             下拉框里不会出现 MP3 选项，只保留 WAV。
  采样率     跟随设备 / 44100 / 48000 / 88200 / 96000
  文件名方式 自动命名（带时间戳），或停止时询问你
  保存目录   默认 exe 同目录下的 Recordings，可以点"更改文件夹"换

【试听】
  · 录完或存完预录后，点「试听」直接播放刚生成的文件
  · 「打开文件」可以试听任意音频：WAV / MP3 / FLAC / OGG / AIFF 等
  · 也可以把音频文件直接拖进窗口

【几个小技巧】
  · 秒数指示器：白色 = 待机　绿色 = 正在往预录缓存里存　黄色 = 正在录音
  · 「待机也显示波形」勾上后，没在录音也能看到实时波形
  · 波形上滚动滚轮 = 横向缩放（以鼠标位置为中心）
    Shift + 滚轮 = 纵向缩放
  · 试听时在波形上按住拖动 = 跳到那个位置
  · 电平表旁边的方点变红 = 削波（音量过大），点一下可以复位
  · 「刻度：LOG(dB)」切换波形纵轴是线性还是对数

【会生成哪些文件】
  settings.json   你的设置（删掉就恢复默认）
  RecLite.log     运行日志（出问题时留着有用，写满 8MB 会轮转出 RecLite.log.1）
  Recordings\     录音和预录文件

【系统要求】
Windows 10 / 11（系统自带 .NET Framework 4.8）。
如果系统提示缺少 .NET Framework，去微软官网装 4.8 版本即可。
